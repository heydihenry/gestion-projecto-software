# 🚀 Gestor de Proyectos de Software

> *"Construye la herramienta que gestiona tu propio desarrollo"*

## 📖 Visión del Proyecto

Este proyecto es un **sistema web completo** para la gestión de proyectos de software, diseñado para ser utilizado por equipos de desarrollo como el nuestro. Es una herramienta que nos permitirá:

- 📋 Crear y administrar proyectos
- 📝 Gestionar requisitos funcionales y no funcionales
- ✅ Descomponer requisitos en tareas y subtareas
- 📎 Adjuntar archivos (diagramas, diseños, documentación)
- 👥 Colaborar en equipo con roles definidos

## 🎯 Objetivo Educativo

**El verdadero propósito** no es solo el software final, sino **aprender el proceso completo de desarrollo**:

1. Captura de requisitos
2. Diseño de base de datos
3. Diseño de arquitectura
4. Diseño de interfaces (UX/UI)
5. Desarrollo (Backend + Frontend)
6. Pruebas (unitarias, integración, aceptación)
7. Despliegue y documentación

## 📋 Reglas de Colaboración

1. **Issues**: Cada tarea es un Issue en GitHub
2. **Branches**: `feature/##-descripcion` (ej: `feature/05-login`)
3. **Commits**: Mensajes claros en español o inglés
4. **Pull Requests**: Mínimo 1 revisor antes de merge
5. **Plazos**: 7 días para completar una tarea asignada
6. **Comunicación**: Canal de WhatsApp para dailies y dudas

## 🔍 Cómo Participar

### 📧 Paso 1: Solicita Acceso

Para mantener un equipo comprometido y de calidad, el acceso es **controlado**.

**Envía un correo a:** `henryhedyi28@gmail.com`

**Asunto:** `Solicitud de participación - [Tu nombre]`

**Cuerpo del correo:**


### ✅ Paso 2: Recibe la Invitación

- Te responderé confirmando tu participación
- Recibirás una **invitación de GitHub** para unirte al repositorio
- Acepta la invitación (revisa tu correo o notificaciones de GitHub)

### 🔑 Paso 3: Acceso al Repositorio

- Tendrás permisos de **colaborador directo**
- Podrás crear branches directamente en el repositorio
- No necesitas hacer fork

### 📌 Paso 4: Elige tu Primera Tarea

1. Revisa los **Issues** disponibles (etiquetados por fase y dificultad)
2. Comenta en el Issue: `"Me asigno esta tarea"`
3. Espera la confirmación del mantenedor

### 🔀 Paso 5: Flujo de Trabajo

```bash
# 1. Clona el repositorio
git clone https://github.com/tu-usuario/gestion-proyectos-software.git

# 2. Crea tu rama (siempre desde main)
git checkout -b feature/##-descripcion-corta
# Ejemplo: feature/05-modelo-usuario

# 3. Trabaja en tu código
git add .
git commit -m "feat: descripción clara del cambio"

# 4. Sube tu rama
git push origin feature/##-descripcion-corta

# 5. Abre un Pull Request en GitHub```
